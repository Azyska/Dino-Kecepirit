## Description

**Dino Kecepirit** is an endless runner browser game inspired by the classic Chrome T-Rex game. Built using React and TypeScript, this project combines fast-paced obstacle-dodging gameplay with educational elements—challenging players with interactive English quizzes along the run.

Originally developed as a final semester assignment (*UAS Bahasa Inggris*), the game also includes manual theme switching that lets players change the visual atmosphere on the fly, including a custom Spring theme with redesigned cactus obstacles.

## Key Features

- **Endless Runner Gameplay:** Smooth jump mechanics and progressive speed scaling as your score climbs.
- **Interactive English Quizzes:** Built-in vocabulary and grammar checkpoints that reward correct answers during gameplay.
- **Dynamic Theme Switcher:** Toggle between visual themes (such as Spring mode) with tailored environment and obstacle graphics.
- **Responsive & Lightweight:** Runs directly in modern desktop and mobile browsers without extra plugins.
